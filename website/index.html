01 / The file manager

Old disks. Modern tools.

Work with CP/M disk images without booting an emulator. Manage files and explore historical media.

IMAGES

Open your collection

RAW, IMD, JV3, DMK and supported standard CPCEMU DSK. Supported TeleDisk images open as unsaved RAW tabs.

FILES

Move files freely

Browse user areas, import, export, rename, delete, edit supported attributes and transfer files between open images.

VIEWER

Look inside the bytes

Read text or hex, preview supported Squeeze and Crunch files and browse nested LBR and ARK archives.

FORMATS

Find the right geometry

Use the bundled cpmtools catalogue, assisted format identification or custom definitions.

CREATE

Build new images

Create or format images and manage reserved system tracks.

SAFETY

Work on a copy

GUI edits remain in a private working copy until Save or Save As.

02 / Disk investigation

Go beyond the directory.

Examine unfamiliar images, compare copies and investigate filesystem inconsistencies. Some structured layouts require verified physical mapping profiles.

ANALYZE

Identify disk formats

Rank plausible definitions and review proposed candidates in the Disk Format Editor.

INSPECT

Physical disk and filesystem

Explore geometry, directory entries, allocation blocks and source sectors where mapping is verified.

COMPARE

Compare images

Compare directory structures and file contents across open images.

CHECK

Investigate corruption

Review inconsistencies and proposed repairs. Supported extent-bit repairs require approval; shared-block findings remain review-only.

DEFINE

Disk Format Editor

Create, duplicate, import, validate and export disk definitions.

EXPLORE

Sector and system areas

View sectors in read-only hex and inspect reserved system tracks.

04 / Command line

Power beyond the GUI.

Workbench bundles cpmtools for command-line use. List, copy, remove and change attributes on CP/M images or use filesystem utilities in scripts.

CLI editing utilities act directly on supplied files, outside the graphical Save and Discard workflow. Use copies of important images.

QUICK REFERENCECLI / v2.0
# List files
cpmwb /cpmls -f ibm-3740 disk.raw

# Utility selectors
/cpmcp    /cpmrm
/cpmchmod /cpmchattr
/mkfs.cpm /fsck.cpm /fsed.cpm

# Override disk definition catalogue
/diskdefs=PATH
