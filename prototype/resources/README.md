# cpmimage app icon

The approved cpmimage icon reads “cp/m image”. It was edited from the CPMArchives GitHub profile icon with the built-in image tool and approved by the owner on 2026-11-10. The edit replaces “inside” with “image” while retaining the original visual style, blue lettering/ring and opaque black background. The final prompt is retained in `cpmimage-edited-prompt.txt`.

`cpmimage.png` is the adopted 1254×1254 image; `cpmimage-edited.png` preserves the approved generated output. SHA-256: `ef07c11970eeb9adea98f68fa604a592dd48e59d65fba6c765b2f5dc138f866f`.

`cpmimage.icns` provides macOS 16–1024 pixel representations. `cpmimage.ico` provides Windows 16, 32, 48, 64, 128 and 256 pixel PNG representations. The Qt resource embeds `cpmimage.png` for the application/window icon on all platforms.

`cpmarchives-original.png` preserves the original 460×460 GitHub profile icon. Source: https://github.com/CPMArchives; downloaded from https://avatars.githubusercontent.com/u/102423494?v=4&s=1024. Original SHA-256: `60b0040e56da4761bb5d91f9f83ffd166de1218c34b624cd1218694080c6a38b`.
